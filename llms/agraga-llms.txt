# Agraga

> Agraga (operated by Virya Logistics Technologies Private Limited) is a Chennai, India based digital
> cross-border logistics platform founded in 2021. It acts as a single operator across every leg of a
> shipment — ocean freight, air freight, domestic transport, customs broking, warehousing, e-commerce
> fulfilment and embedded trade finance — booked and tracked from one platform, aimed particularly at
> Indian MSME exporters and importers.

## API status

Agraga publishes **no public API, no developer portal, no SDK and no machine-readable API contract**.
This file is generated by API Evangelist from the public profile at
https://github.com/api-evangelist/agraga — it is not published by Agraga.

- No OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema is published at any Agraga host.
- No MCP server and no A2A agent card is served on any Agraga host.
- No `/.well-known/` document is served anywhere on the estate (63 path/host probes, 0 documents).
- The platform backends (api.agraga.com, pricing.agraga.com) are private services behind a blanket
  authentication filter that returns HTTP 401 for every anonymous request, including the well-known
  namespace. They are the backends of the company's own web application, not a product API.

## Services

- Ocean Freight: FCL and LCL cross-border ocean shipping.
- Air Freight: time-critical air cargo movements.
- Customs Broking: customs clearance and trade compliance.
- Warehousing: storage, pick/pack and cross-dock with inventory visibility tied to tracking.
- E-Commerce Fulfilment: fulfilment capacity that scales for peak season.
- Embedded Finance: trade and working-capital finance embedded in the shipment flow.

## Notes for agents

- There is nothing here an agent can call. Pricing is quoted per shipment inside the authenticated
  booking platform; there is no self-serve plan, no published rate card and no rate-limit contract.
- The correct entry point for a machine integration today is a human one: the contact page.
